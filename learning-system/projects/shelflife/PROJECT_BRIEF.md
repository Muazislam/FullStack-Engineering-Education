# ShelfLife Project Brief

ShelfLife is the main project for the JavaScript to React curriculum.

## Product Idea

A personal reading and learning library where a user can track books, reading
status, ratings, notes, search results, and reading stats.

## Evolution

- Module 0: plain JavaScript data engine.
- Module 1: static React UI.
- Module 2: interactive local state.
- Module 3: reducer and context architecture.
- Module 4: Open Library API, persistence, custom hooks.
- Module 5: measured performance improvements and modern React features.
- Module 6: routing, query caching, forms, TypeScript, tests, accessibility.
- Module 7: deployed portfolio app.

## Quality Bar

Every feature should have:

- a realistic user reason,
- a clear data shape,
- at least one edge case,
- an explanation of the implementation approach,
- a note about what could be improved later.
